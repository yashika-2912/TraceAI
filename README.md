
TraceAI – Attribution-First AI Content System

An AI-powered content generation platform that provides granular attribution lineage for every generated paragraph, built with Google Generative AI.

🎯 Overview
TraceAI is an Attribution Honesty System (AHS) that transforms how students and developers use AI for content creation. Unlike traditional AI tools that generate output with surface-level citations, TraceAI quantifies source influence, AI synthesis, and user originality in real time.
🚀 Key Features
1. Paragraph-Level Attribution Breakdown

Clear percentage-based attribution for each generated paragraph
Distinguishes source influence, AI synthesis, and user originality

2. Originality Risk Heatmap

Visual highlighting with color-coded risk levels: 🟢 Low | 🟡 Medium | 🔴 High
Identifies sections dependent on reference sources

3. Integrity Control Modes

Assignment-Safe Mode – Strict similarity thresholds for academic work
Research-Draft Mode – Moderate source dependency allowed
Creative Mode – Flexible thresholds for original thinking

4. Explainable AI Transparency Panel

Exposes retrieved source snippets and generation context
Shows how AI arrived at the output
Full audit trail for accountability
